# Карта проекта ЕС Клиники

Этот файл описывает текущую рабочую версию после удаления лабораторных страниц. Главная страница и архивные страницы клиники обслуживаются одним приложением Next.js.

## Как открывается сайт

```text
app/layout.jsx
└── app/page.jsx
    └── app/scroll-version/landing.jsx
        ├── app/ui/rebuilt-hero.jsx
        ├── остальные секции главной
        └── компоненты из app/ui/
```

- `app/layout.jsx` — общий HTML-каркас, метаданные сайта, локальные шрифты и раннее восстановление настроек редактора из `localStorage`.
- `app/page.jsx` — маршрут `/`. Он передаёт страницу главной в `ScrollVersionLanding`.
- `app/scroll-version/landing.jsx` — сборка главной и порядок её секций. Активный первый экран — `RebuiltHero`; далее идут блоки подхода, семьи, системы здоровья, заявки, ответственности, процесса, сравнения, команды, контракта, партнёров, истории, отзывов, вопросов и контактов.
- `app/[slug]/route.js` — маршруты сохранённых страниц по адресу `/<slug>`. HTML этих страниц хранится в `app/data/original-pages.json`; неизвестный адрес возвращает 404, а `medicalfamilyoffice` перенаправляется на `/`.

## Компоненты страницы

| Файл | За что отвечает |
| --- | --- |
| `app/ui/rebuilt-hero.jsx` | Первый экран: навигация, контакты, меню и карточка медицинской команды. |
| `app/ui/interactive.jsx` | Общие интерактивные элементы: видео, раскрывающиеся шаги и отзывы, шапка старого варианта первого экрана, форма заявки и кнопка консультации. |
| `app/ui/editor.jsx` | Встроенный редактор текста, фотографий, типографики и положения элементов. Изменения остаются в браузере пользователя и переносятся через экспорт/импорт. |
| `app/ui/comparison-scroll.jsx` | Интерактивный блок сравнения сопровождения с клиникой и без неё. |
| `app/ui/contract-scroll-story.jsx` | История и состав годового контракта с раскрывающимися группами услуг. |
| `app/ui/contact-widget.jsx` | Плавающие кнопки телефона и мессенджеров. |
| `app/ui/scroll-effects.jsx` | Появление элементов при прокрутке и эффекты секций. |

### Стили

- `app/globals.css` — базовая типографика, сетка и стили большинства секций главной, включая систему здоровья и заявку.
- `app/ui/original-first-screen.module.css` — стили первого экрана и меню. Имя файла историческое: его использует `rebuilt-hero.jsx`.
- `app/ui/comparison-scroll.module.css` — оформление сравнения.
- `app/ui/contract-scroll-story.module.css` — оформление блока контракта.
- `app/ui/contact-widget.css` — плавающие контакты.

## Тексты и данные

| Файл | Содержимое |
| --- | --- |
| `app/data/copy.json` | Тексты главной страницы, выбираемые по индексам в `landing.jsx` и компонентах. |
| `app/data/faqs.json` | Вопросы и ответы. |
| `app/data/partners.json` | Данные о партнёрах. |
| `app/data/contact-widget.json` | Подписи, адреса и SVG для плавающих контактов. |
| `app/data/photo-sources.js` | Сопоставление логических имён фотографий с файлами в `public/assets`. |
| `app/data/original-pages.json` | Снимки HTML дополнительных страниц: врачи, документы, контакты и другие разделы. |
| `app/data/linked-page-documents.json` | Сопоставление исходных адресов документов с локальными файлами. |

Форма заявки сейчас проверяет заполнение полей в браузере, но не отправляет заявку на сервер. После заполнения она показывает инструкцию связаться с клиникой.

## Изображения, документы и шрифты

- `public/assets/` — изображения главной, фото врачей, варианты фотографий, логотипы, иконки и обложки видео. Подкаталоги `enhanced`, `doctors-original`, `partners`, `partners-mono`, `section-icons` и `original-first-screen` группируют эти материалы по назначению.
- `public/linked-pages/documents/` — локальные PDF и DOCX, на которые ссылаются архивные страницы.
- `public/clinic-favicon.ico` — значок сайта.
- `app/aeroport.woff`, `app/fonts/` и `public/assets/official-geologica.woff` — файлы шрифтов.

## Настройки и команды

- `package.json` — команды запуска, сборки, подготовки ресурсов и тестов; основные зависимости проекта.
- `package-lock.json` — закреплённые версии npm-пакетов.
- `next.config.mjs` — каталог сборки Next.js и настройки отдачи изображений.
- `npm run dev` — локальный сервер на `127.0.0.1:5175`.
- `npm run build` и `npm start` — production-сборка и её запуск на `127.0.0.1:4175`.
- `npm test` — тесты из `tests/`.

## Служебные файлы

- `scripts/` — сценарии подготовки исходных фотографий и логотипов, импорта первого экрана и архивных страниц, локального предпросмотра и отдельных проверок.
- `tests/landing.test.mjs` и `tests/layout.test.mjs` — проверки главной страницы, редактора, секций и геометрии.
- `README.md` — запуск проекта и общие заметки.
- `AGENTS.md` и `CLAUDE.md` — инструкции для инструментов разработки; это не части сайта и не пользовательские тексты.

## Где менять конкретные вещи

- Текст главной — `app/data/copy.json`; содержимое секций и их порядок — `app/scroll-version/landing.jsx`.
- Размеры и расположение секций — `app/globals.css`.
- Первый экран и меню — `app/ui/rebuilt-hero.jsx` и `app/ui/original-first-screen.module.css`.
- Фотографию, назначенную по имени, — `app/data/photo-sources.js`; сам файл — в `public/assets/`.
- Логику формы — `ConsultationLeadForm` в `app/ui/interactive.jsx`; внешний вид — в `app/globals.css`.
- Архивную страницу по адресу `/<slug>` — запись с таким ключом в `app/data/original-pages.json`.
