# ЕС Клиника — отдельная версия по обновлённому документу

Next.js App Router. Исходная версия в соседней папке `site` не заменяется.

## Локальный запуск

```sh
npm install
npm run dev
```

Dev: http://127.0.0.1:5175

Для проверки скорости без dev-компиляции:

```sh
npm run build
npm start
```

Оптимизированная сборка: http://127.0.0.1:4175

## Содержание и редактор

`app/data/copy.json` содержит текст обновлённого документа «Новая главная_NEW». Из 106 записей 96 — текст, 10 — указания по расположению и иллюстрациям. Текстовые записи представлены на странице. FAQ и партнёры вынесены в отдельные файлы данных.

Система управления здоровьем: фото бабушки с внуком слева, текст справа. Медицинская ответственность: текст слева, ресепшен справа. Далее — текстовый таймлайн, сравнение, команда, контракт, партнёры, история, лояльность, отзывы, FAQ и контакты.

Кнопка «Изменить» открывает редактор. Выбор элемента временно скрывает панель. Можно менять текст, шрифт, размер, интервал, начертание, цвет, выравнивание, ширину, фотографию. Изменения сохраняются только в текущем браузере (localStorage); для переноса служат экспорт и импорт JSON. Общего серверного хранилища нет. Загрузка изображений ограничена 3 МБ; большие фотографии могут превысить квоту браузера.

Контактные кнопки открывают телефон и Telegram клиники; отправка заявок на сервер не реализована.

## Положение и размер элементов

Выбор охватывает также иконки, логотипы, кнопки, ссылки, видео-карточку и группы элементов. Фоновая фотография первого экрана и фон секций исключены. «Выбрать группу выше» выбирает родительский контейнер.

Поля X/Y и стрелки (шаг 10 px) визуально сдвигают элемент относительно исходного места, не меняя порядок соседей. Масштаб изменяет элемент целиком, ширина и высота задаются в пикселях (пустое поле — автоматически). Произвольные смещения могут привести к наложениям на узких экранах: проверяйте мобильную версию. Геометрия сохраняется в черновике и переносится через JSON. Отдельная кнопка сбрасывает её, сохраняя текст и фото.

## Производительность

Страница предварительно рендерится. Крупные фоновые фотографии, постер видео и миниатюры врачей подготовлены в WebP; остальные фотографии выдаются через next/image. Шрифт Aeroport локальный. Видео загружается после наведения мыши или нажатия Play. Старые скрипты Tilda и прелоадер не используются. Результаты локального аудита описаны в `AUDIT_REPORT_2026-09-26.md`.

`npm run prepare:assets` заново подготавливает ресурсы из соседней папки `site`, не меняя исходники.

## Проверки

`npm test`: разделы страницы, меню, контактный диалог, форму, отложенную загрузку видео, FAQ, редактор с сохранением после перезагрузки и экспортом/импортом, отсутствие горизонтального переполнения на 390/768/1024/1440 px, ошибки браузера и HTTP.

Тест требует установленный Playwright Chromium, либо путь к установленному Chrome в `TEST_CHROME`, либо `TEST_CDP` с адресом работающего браузера. `TEST_URL` переопределяет адрес тестирования (по умолчанию порт 4175). Локальную нагрузку можно повторить командой `node scripts/load-audit.mjs` при запущенном `npm start`.

Публикация в GitHub/Vercel выполняется отдельно, после согласования.
