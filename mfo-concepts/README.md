# Варианты блока «Как работает Медицинский Family Office»

Отдельный статический прототип для сравнения исходного блока и пяти вариаций. Повторены палитра, шрифты, заголовок и восемь этапов основного сайта. Основной сайт в `app/` не меняется.

Запуск из папки `mfo-concepts`:

```powershell
python -m http.server 5176 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:5176/`. Проверка взаимодействий и мобильной ширины из корня основного проекта: `node mfo-concepts/verify.mjs`.
