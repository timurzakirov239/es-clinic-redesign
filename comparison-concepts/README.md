# Четыре варианта блока сравнения

Отдельная HTML-страница с четырьмя оформлениями первых трёх пар «Без ЕС Клиники / С ЕС Клиникой». Основной сайт не меняется.

Запуск из папки `comparison-concepts`:

```powershell
python -m http.server 5177 --bind 127.0.0.1
```

Адрес: `http://127.0.0.1:5177/`. Проверка с корня основного проекта: `node comparison-concepts/verify.mjs`.
